# Quality gates

Before delivery, check internally: reader/outcome clear; linear reading path; type and role purity; evidence-backed conclusions; executable procedures with prerequisites/actions/observable results; purposeful artifacts and valid links; no sensitive data; correct split/navigation; no author-side exclusions, historical comparisons, or lists of intentionally unwritten content.

If a gate fails, delete or relocate noise, reorganize, seek evidence, or ask the user for a decision. Do not include this checklist in the final document.
