# Deployment and Implementation Plan

Use for a one-time installation, release, migration, or cutover; do not use as a long-term operations manual.

Path: scope and roles → readiness check → implementation → validation → rollback → delivery acceptance.

Required: objective/scope/environment/responsibility; pre-check; ordered tasks with owners; acceptance criteria; rollback trigger/steps; dependencies/risks/escalation; completion confirmation. Optional: schedule, migration validation, cutover rehearsal. Exclude unresolved design choices and copied long-term runbooks. Split complex work into control plan, readiness, deployment, migration, validation, and rollback documents.

Check: every production-affecting action has owner, result, and rollback treatment.
