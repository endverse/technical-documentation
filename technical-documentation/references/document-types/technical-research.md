# Technical Research Report

Use to decide whether a technology or option meets stated business needs; do not use for a completed acceptance test.

Path: business goal and hard constraints → evaluation criteria → verification design → result matrix → adopt/do-not-adopt conclusion.

Required: goal/constraints; criteria and pass standards; verification environment/method; matrix of requirement, method, result, fit, condition; explicit conclusion. Optional: candidate comparison, cost/migration impact, core evidence appendix. Exclude install/debug history, generic pros/cons, and unverified recommendations. Split detailed evidence from the conclusion report when it obscures the result.

Check: every criterion maps to a need and every conclusion maps to evidence.
