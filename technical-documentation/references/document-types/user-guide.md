# User Guide

Use for a tenant, ordinary user, or business role completing one business task; do not use for administrator maintenance.

Path: when to perform task → prerequisites → ordered actions → completion result → directly related next action.

Required: target reader/task; prerequisites; numbered procedure; verification. Optional: next action, small task-specific troubleshooting, real conditional branches. Describe only the reader's usable path; do not explain which other roles, systems, or documents are excluded. Exclude system design, full field reference, unrelated troubleshooting, and other-role instructions. Use a tutorial-style guide only when several dependent tasks form one end-to-end goal.

Check: the reader can perform the task top-to-bottom without looking ahead.
