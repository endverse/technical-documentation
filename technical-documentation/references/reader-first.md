# Reader-first principles

以下原则是每个内容、结构和表达决策的判定依据；写作和复查（reader revision）时逐条套用，冲突时按「约束栈」排序。改编自 lark-doc authoring philosophy，去掉了飞书 XML 专属的组件与编号机制，保留原意。

- **读者本位**：落地前先回答：读者是谁、为什么要读、带着什么任务来。按读者的任务组织内容，不按功能或作者视角罗列。
- **结构先行**：结论先行，先整体后局部；按逻辑分组与递进，依据信息关系选择列表、步骤或表格，使内容便于扫读。
- **语义先行**：先确定全篇主线和每节的中心任务或命题，再定结构。文档脱离讲解仍须完整、连续、可独立阅读——假设读者没有参加过讨论，凡是"在场才懂"的地方都是缺陷。
- **最低理解成本**：选择最能降低读者理解、执行和出错成本的表达形式，而不是字符最少或写作成本最低的形式；删冗余，用短句、动词和数据，按真实信息关系选用图、表。
- **克制且连贯**：每个元素必须承担导航、比较、解释、证据或行动功能；相关文字与视觉相邻，同类关系复用同类形式。去掉后不影响读者任务的装饰删除。
- **约束栈**：事实（claim sheet 与证据，fail-closed）> 用户硬约束 > 读者任务 > 内容组织 > 呈现格式。后项不得牺牲或放宽前项；格式与排版不得反向改变内容判断。
- **表达一致**：同一对象、动作和状态全文同名；标题靠层级表达结构，不手写序号；混用编号体系时保持层级一致，不出现上一层用中文序号、下一层直接接阿拉伯小数的情况。

这些是判定依据，不是写作模板。具体执行规则见 [presentation](presentation.md)、[common rules](common-rules.md) 和 [quality gates](quality-gates.md)。
